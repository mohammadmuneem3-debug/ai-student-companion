# QR Maker

A simple, fast, and professional web application for creating QR codes for websites, Wi-Fi networks, WhatsApp chats, contacts, UPI payments, and text.

## 📌 About the Project

**QR Maker** is a responsive QR code generator built with HTML, CSS, and JavaScript.

The application provides separate generators for different types of information, making it easy to create and download QR codes without complicated setup.

The project was designed with a clean, modern **dark teal interface** that works across desktop and mobile devices.

---

## ✨ Features

* 🌐 **Website QR** — Create QR codes for website URLs
* 📶 **Wi-Fi QR** — Share Wi-Fi network information
* 💬 **WhatsApp QR** — Create QR codes for WhatsApp chats with optional messages
* 👤 **Contact QR** — Create QR codes containing contact information
* ₹ **UPI QR** — Create UPI payment QR codes
* 📝 **Text QR** — Convert text into a QR code
* 📐 **Multiple QR Sizes** — 300×300, 500×500, and 800×800
* ⬇️ **Download QR** — Download generated QR codes as PNG images
* 📋 **Copy QR** — Copy the generated QR code when supported by the browser
* 🔄 **Regenerate** — Quickly regenerate the current QR code
* 🧹 **Clear** — Clear the current generator
* ⚡ **Loading State** — Visual feedback while generating QR codes
* ❌ **Input Validation** — Helpful messages for invalid or missing information
* 📱 **Responsive Design** — Optimized for desktop and mobile screens
* 🎨 **Premium Dark Teal UI** — Modern and professional interface
* 🔖 **Custom Favicon**
* 🔍 **SEO Meta Description**

## ⚙️ How It Works

### 1. Choose a Generator

Select the type of QR code you want to create:

* Website
* Wi-Fi
* WhatsApp
* Contact
* UPI
* Text

### 2. Enter Your Information

Fill in the required information for the selected generator.

### 3. Generate the QR Code

Click **Generate QR Code** and the application creates your QR code.

### 4. Download or Copy

Once generated, you can download the QR code as a PNG image or copy it when supported by your browser.
